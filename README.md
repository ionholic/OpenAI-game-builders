# 월하진혼

Phaser 4 + Vite + TypeScript로 제작한 한국 설화풍 탑다운 액션 게임입니다. 세 전장의 다섯 스테이지를 돌파하고 중앙 제단의 봉인 다섯 개를 정화하세요.

## 온라인 플레이

https://ionholic.github.io/OpenAI-game-builders/

## 확장 콘텐츠

- 전장: 사당의 달뜰, 통곡의 죽림, 장승의 관문, 핏빛 월궁, 망월대
- 일반 요괴: 도깨비, 귀신불, 갓귀신, 불가사리
- 보스: 도깨비 대장, 저승사자, 월식 불가사리
- 신규 패턴: 고속 추적, 중장갑 돌진, 삼연탄, 오연탄
- 4프레임 스프라이트 시트와 상태 모션: 대기, 이동, 공격, 대시, 피격, 부유, 시전, 공격 준비
- 안전 여백과 발 기준점을 정규화한 주인공 32프레임 강화 시트: 대기, 달리기, 베기, 강공격, 부적 투척, 방어, 대시, 피격의 4단계 동작
- 1920×1080 내부 렌더링과 1280×720 논리 좌표를 결합한 고해상도 출력
- 셀 경계 잘림을 방지한 월광 검기, 강공격 충격파, 비행 부적, 적 요기 탄환의 16프레임 전투 이펙트 시트
- 3단 기본 공격 콤보, 대시 베기, 완벽 방어 후 반격
- 적중·사망 효과와 실제 공격 범위에 맞춘 보스 위험 경고
- P 일시정지 메뉴에서 V 음량 및 G 고화질/성능 모드 전환

## 실행

```powershell
npm install
npm run dev
```

브라우저에서 `http://127.0.0.1:4173`을 엽니다.

## 조작

- 이동: `WASD` 또는 방향키
- 공격: 마우스 왼쪽, `J`, `Space`
- 강공격: `E` — 주위 넓은 범위에 78 피해
- 부적 투척: `Q` — 직선 원거리 공격
- 방어/튕겨내기: `C` — 피해 감소, 입력 직후 0.18초 완전 방어
- 대시: `Shift` 또는 마우스 오른쪽
- 정화: 제단 안에서 `R` 유지
- 전체화면: `F`
- 일시정지: `P` — 메뉴에서 `V` 음량, `G` 화질 전환
- 재시작: 결과 화면에서 `R`

## 조작감 개선

- 공격·강공격·부적·대시에 0.14초 선입력 버퍼
- 대시로 공격 동작을 취소해 위험 지역에서 빠르게 이탈
- 근접 적중 시 짧은 타격 정지와 화면 충격
- 부적 투척에 전방 24도·420px 범위 자동 조준 보정
- HUD에서 강공격·부적·튕겨내기의 준비 및 재사용 시간을 즉시 확인
- 연속 `J` 공격은 34 → 40 → 52 피해의 3단 콤보
- 대시 직후 0.72초 안의 공격은 58 피해의 대시 베기, 완벽 방어 뒤 0.75초 안의 공격은 76 피해의 반격

## 검증

```powershell
npm run build
npm run test:acceptance
```

자동 테스트는 개발 서버가 `127.0.0.1:4173`에서 실행 중일 때 사용합니다.

생산 빌드를 직접 확인하려면 다음을 사용합니다.

```powershell
npm run build
npm run preview
$env:GAME_URL='http://127.0.0.1:4174'
npm run test:acceptance
```

검증 결과와 화면 캡처는 `output/acceptance/`에 저장됩니다. 생성 이미지 원본·최적화 방식·프롬프트는 `ASSET_MANIFEST.md`에 기록되어 있습니다.

## 구조

- `src/scenes/`: 로딩, 시작, 전투, 결과 장면
- `src/testing/StateBridge.ts`: `render_game_to_text()`와 고정 스텝 `advanceTime(ms)`
- `public/assets/generated/`: 게임이 실제 로드하는 최적화 에셋
- `assets/source-generated/`: 이미지 생성 도구의 고해상도 원본
- `tests/`: 공식 게임 클라이언트 사본과 전체 수용 테스트
- `dist/`: 정적 호스팅 가능한 생산 빌드
